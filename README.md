## 📌 About the Project

This project was developed as a **college mini project** under the **Clean & Green Technology** theme.

The system provides a simple interface where users can explore the platform, report civic issues, interact with a chatbot, and learn how digital solutions can improve communication between citizens and local authorities.

**Note:** This project is a frontend prototype intended for demonstration and academic purposes.

## ▶️ How to Use

</div>

1. Clone this repository

```bash
git clone https://github.com/your-username/Crowdsourced-Civic-Issues-Reporting-System.git
```

2. Open the project folder.

3. Launch **index.html** in any modern web browser.

4. Navigate through the different pages to explore the prototype.

> **Note:** This project contains only the frontend implementation. Backend functionalities such as complaint storage, authentication, and real-time tracking are not included.
